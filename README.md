# 26^4 Personalities!

## 概要
16 Personalities (いわゆる MBTI 診断) には 16 個の診断結果がありますが，人間を表すのに 16 種類ではとても少ないと思いませんか？

ということで 13 問で 181657 個の診断結果がある性格診断を作りました！

あなたにピッタリの 4 文字を見つけましょう！！

13 問の質問に回答することであなたの 4 文字を提案いたします。

という体のゲームです。

React / TypeScript / Supabase を使用した，リアルタイム集計型の Web アンケートゲームアプリです。

プレイはこちらから(Vercel)→　https://26powered4personalities.vercel.app

## 特徴と工夫
- 個人情報を問うような質問は無く，収集している情報は回答および回答時刻のみです
- 過去の回答に応じて診断結果が変化する可能性があるユニークなゲームです
- React を用いて分かりやすい状態管理を行うコードを書くことを心がけました

## 今後の課題
ウェブデザインが簡素すぎてユーザーの体験として続けようと思いにくいものになってしまっています。シンプルで分かりにくいということは無いと思いますが，UI/UX 向上のためにデザインを見直すとさらに良いアプリになると考えられます。具体的にはラジオボタンの大きさを大きくして回答しやすくするなどの改善が考えられます。
